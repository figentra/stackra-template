Written by `stackra gen` from `stackra.config.ts`, `runway.yaml`, `src/config/*.config.ts`, the
decorated classes under `src/` (`@App`, `@Route`, `@Layout`, `@Block`, `@Menu`, `@Flag`,
`@AnalyticsEvent`), `assets/` (with the string overrides in `assets/overrides/`) and the consumed
services' manifests (inferred from `#stackra/clients` imports). A real project ignores everything
but `app-manifest.json`; the template commits the samples so they can be read. Every file opens with
`generated by stackra gen from <sources> — do not edit` and is complete. Shorthand: `S` =
stackra.config.ts, `C/<fact>` = src/config/<fact>.config.ts, `RM` = this member's runway.yaml, `RR`
= the root runway.yaml, `D` = decorated classes.
