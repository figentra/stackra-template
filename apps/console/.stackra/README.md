# apps/console/.stackra (generated; only `app-manifest.json` is committed)

Written by `stackra gen` from `stackra.config.ts`, `runway.yaml`, `src/config/*.config.ts`, the decorated classes under
`src/` (`@App`, `@Panel`, `@Route`, `@Layout`, `@Provider`, `@Store`, `@Menu`, `@Command`, `@Bridge`, `@Block`,
`@Document`, `@Override`), `assets/`, `src/overrides/` and the consumed services' committed manifests (inferred from
`#stackra/clients` imports). A real project ignores everything but `app-manifest.json` and rebuilds the rest on
`pnpm gen`, on save under `stackra dev`, and before `build`, `test` and `typecheck`. The template commits the samples so
they can be read. Every file opens with `generated by stackra gen from <sources> — do not edit` and is complete.
Shorthand: `S` = stackra.config.ts, `C/<fact>` = src/config/<fact>.config.ts,
`RM` = this member's runway.yaml, `RR` = the root runway.yaml, `D` = decorated classes, `M` = consumed manifests.
