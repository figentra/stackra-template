# apps/mobile/.stackra (generated; gitignored except `app-manifest.json`; committed in this template only to be read)

Everything here is written by `stackra gen` from `stackra.config.ts` (S), `runway.yaml` (RM), the
root `runway.yaml` (RR), `src/config/*.config.ts` (C/<fact>), `mise.toml` (T), the decorated classes
under `src/` (D: `@App`, `@Route`, `@Layout`, `@Provider`, `@Store`, `@Block`, `@Document`, `@Menu`,
`@Override`, `@Config`, `@AnalyticsEvent`) and the consumed services' committed manifests (M;
inferred from `#stackra/clients` imports). A real project ignores `.stackra/*` except the committed
`app-manifest.json`, and rebuilds the rest on `pnpm gen`, on save under `stackra dev`, and before
`build`, `test` and `typecheck`. Every file starts with `generated by stackra gen from <sources> —
do not edit`.

Expo CLI and EAS read their config from the member ROOT, so gen also writes four thin root shims,
all gitignored: `app.config.ts`, `babel.config.js`, `metro.config.js` (one-line re-exports of the
files below) and `eas.json` (a copy; JSON cannot re-export). `package.json` `main` points at
`.stackra/main.ts`, so no entry shim is needed.
