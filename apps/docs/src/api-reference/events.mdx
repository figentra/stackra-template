Subscribe through a webhook subscription (Standard Webhooks signing) for events marked webhook, or,
inside the platform, with a listener whose `handle` takes the event class the producer's generated
client exports (`handle(event: Commerce.OrderPlaced, ctx)`). Names are
`<module>.<aggregate>.<verb>.v<n>`; a new major is a new name, and the old one keeps flowing until
the sunset its change file sets.

Every envelope is `{ id, name, version, occurredAt, tenantId, actor, data }`; `data` is the schema
below. Ids are public ids (`ord_…`, `usr_…`); money is in minor units with its currency.

## orders

### `orders.order.placed.v1`

Recorded when an order is created, before payment is authorised. Consumers: loyalty (redeem),
notifications (confirmation).

```json
{
  "orderId": "ord_01J…",
  "customerId": "usr_01J…",
  "totalMinor": 24000,
  "currency": "SAR",
  "lines": [{ "variantId": "var_01J…", "quantity": 2 }]
}
```

### `orders.order.paid.v1`

Recorded when the payment is captured. Also delivered to webhook subscriptions. Consumers: loyalty
(earn), notifications (receipt).

```json
{
  "orderId": "ord_01J…",
  "customerId": "usr_01J…",
  "paymentId": "pay_01J…",
  "totalMinor": 24000,
  "currency": "SAR"
}
```

### `orders.order.cancelled.v1`

Recorded when an order leaves its lifecycle; `reason` says who or what ended it (`customer`,
`staff`, `expired`, `payment_failed`).

```json
{ "orderId": "ord_01J…", "customerId": "usr_01J…", "reason": "customer" }
```

## catalogue

### `catalogue.product.archived.v1`

Recorded when a product stops selling; carries its variant ids so consumers need no lookup.
Consumers: search (drop from the index), the storefront cache (purge).

```json
{ "productId": "prd_01J…", "variantIds": ["var_01J…"] }
```

## inventory

### `inventory.stock.low.v1`

Recorded when a variant's available stock at a location falls to the tenant's low-stock threshold
(the `inventory.lowStockThreshold` setting) or below. Broadcast on the tenant's realtime channel to
sessions holding `inventory.stock.read`; it is not delivered to webhooks.

```json
{ "variantId": "var_01J…", "locationId": "loc_main", "available": 3 }
```

## loyalty_kit

Merged from `@acme/loyalty-kit`; ids are the kit's (`memberId` is the commerce customer id).

### `loyalty_kit.account.enrolled.v1`

Recorded when a customer gets a loyalty account (explicitly, or on their first paid order).

```json
{ "accountId": "01J…", "memberId": "usr_01J…", "tier": "bronze" }
```

### `loyalty_kit.points.earned.v2`

Recorded when points are credited; `tier` is `bronze`, `silver` or `gold`. Until 2027-04-01
`loyalty_kit.points.earned.v1` is also published, with `memberId`, `points` and `reference` only.

```json
{
  "memberId": "usr_01J…",
  "points": 240,
  "reference": "ord_01J…",
  "tier": "silver",
  "balanceAfter": 1240
}
```

### `loyalty_kit.account.frozen.v1`

Recorded when an account is frozen or unfrozen.

```json
{ "accountId": "01J…", "memberId": "usr_01J…", "isFrozen": true }
```

## Not public

Domain events carry no version: they never leave the producing service, so their shape changes with
its code, and they are never broadcast. `loyalty_kit.points.redeemed`
(`{ memberId, points, reference }`) stays inside the service.
