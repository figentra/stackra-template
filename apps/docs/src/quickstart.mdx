---
title: "Quickstart"
description: "From clone to a placed order."
icon: "rocket"
---

<Steps>
  <Step title="Install the toolchain">
    `mise install` pins Node, pnpm, the Encore CLI and gitleaks. Then `pnpm install`.
  </Step>
  <Step title="Generate">
    `pnpm gen` runs `stackra gen` in every member: the service's `app-manifest.json`, the console's
    routes and clients, the site's clients and sitemap sources, and this site's API reference.
  </Step>
  <Step title="Run everything">
    `pnpm dev` starts the service (gen in watch mode plus the generated Encore app), the console,
    the site and these docs, each on the port its own `runway.yaml` names; `stackra dev` prints them
    and writes them to `.stackra/dev/ports.json`. Secrets come through `infisical run`; nothing is
    in a file.
  </Step>
  <Step title="Place an order">
    Open the console, log in as the seeded staff user, and use Quick order. Or call the API through
    the dev gateway (`GATEWAY` is its origin from `.stackra/dev/ports.json`):

    ```bash
    curl -X POST "$GATEWAY/orders" \
      -H "Authorization: Bearer $TOKEN" -H "Idempotency-Key: $(uuidgen)" \
      -H "Stackra-Version: 2027-03-01" \
      -d '{"lines":[{"variantId":"var_01JA0000000000000000000001","quantity":1}]}'
    ```

    The response is the order id and a payment client secret; `orders.order.placed.v1` is on the
    bus.

  </Step>
  <Step title="Verify before you push">
    `pnpm verify` is the gate: format, lint, typecheck, test, build, `stackra gen --check`, `stackra
    validate`.
  </Step>
</Steps>
