Acme Retail is a `pnpm create stackra` project. It has one service (`@acme/service-commerce`:
catalogue, inventory, orders, loyalty), the console that renders what that service declares, the
public site, and this documentation. Everything a page here says about the API is generated from the
service's committed manifest, so it cannot drift from the code.

## Reading order for a new contributor

1. `AGENTS.md` at the repository root: the programming model v3.1 grammar, the group folders, the
   kind table and the dictionary.
2. `services/commerce/src/modules/orders/README.md`, then `actions/create-order.action.ts`.
3. The [programming model](/guides/programming-model) guide.
4. [Add a field end to end](/guides/add-a-field): one change through every file it touches.
5. One ADR, [0001](/adr/0001-loyalty-ledger-is-a-port), to see how a decision is recorded.
