Acme is a placeholder product started from the Stackra template (`product.key: acme` in the root
`runway.yaml`). The starter is lean: one example service (`services/example`,
`@figentra/acme-service-example`), one example package (`packages/application/example`,
`@figentra/acme-example`) and this documentation. Both examples are exactly what `stackra new`
writes, with no modules yet; rename them to your first service and package, or delete them. A
product adds apps only when it needs one.

## Reading order for a new contributor

1. `AGENTS.md` at the repository root: the programming model v3.1 grammar, the group folders, the
   kind table and the dictionary.
2. `README.md` at the repository root: the structure, how each member kind is created and what to
   replace.
3. The [programming model](/guides/programming-model) guide, then [testing](/guides/testing).
4. `services/example/README.md` and `packages/application/example/README.md`, before you rename or
   replace them.
