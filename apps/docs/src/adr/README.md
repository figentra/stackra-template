# adr

The project's own architecture decision records, in the house format (Context, Decision,
Consequences, Enforcement, Supersedes and sources). `index.mdx` is the table; each record is
`NNNN-short-title.mdx`, numbered from the highest existing plus one. An accepted ADR is never
rewritten: a later one supersedes it in the same commit, and both pages point at each other. A new
record is added to `index.mdx` and to `docs.json`.

Stackra's own ADRs (the framework's) are cited by number with the `stackra/` prefix so the two
sequences never mix.
