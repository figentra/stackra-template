# Security policy

## Reporting a vulnerability

Do not open a public issue. Report privately, by either route:

- GitHub: "Report a vulnerability" on the repository's Security tab (private vulnerability reporting).
- Email: security@your-domain.example (replace it, README "Make it yours").

Include the affected member, the version or commit, steps to reproduce, and the impact you see.

## What to expect

- Acknowledgement within three business days.
- A fix or mitigation plan once the report is confirmed, and credit in the advisory if you want it.

## Scope

The apps, services and packages in this repository. Never put a secret value in a report; name the secret instead.
